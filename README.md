# Leafys Mayhem
## requirements
1. a Legal copy of borderlands 3 (steam, epic, gog) all should work
2. the sdkmod loader for bl3 [bl3 mod database](https://bl-sdk.github.io/oak-mod-db/)

## how to setup
1. setup the sdkmod loader above
2. after you have the mod loader setup grab the [latest release](https://github.com/OnlyLeafeon/Leafys-Mayhem/releases)
3. unzip the mod into the sdk_mods folder (ensure that when you click into the mods folder it has the python files not another folder)
